# Agent guidance — php-io-extensions/harfbuzz

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing the API, the C, or packaging. Open only the concepts the change touches.
2. **HarfBuzz, 1:1, at the 8.3.0 API.** One PHP function = one HarfBuzz function, under its C name and signature, every C parameter its own PHP parameter in C order. Constants are the C constants, registered with `@cvalue`; not class constants, not enums. No defaults the C call lacks, no composites, no conveniences. Nothing newer than 8.3.0: the gaming PC's HarfBuzz is 8.3.0, so a newer symbol fails its build. HarfBuzz's behaviour passes through: empty results, invalid languages and odd but documented results reach PHP as HarfBuzz produces them.
3. **Refusals.** The rule, verbatim:
   > A refusal is the extension declining to make the native call. The extension may refuse only when making it would cause (1) memory unsafety — the call would dereference a native object the PHP wrapper no longer validly references; (2) uncatchable process death — SIGSEGV, SIGBUS, abort(), or an ObjC/C++ exception unwinding through Zend frames; (3) VM corruption — PHP code run on a non-PHP thread or illegal engine re-entry. Nothing else justifies a refusal: return codes, nil, clamping, logs, odd but documented results pass through. Every refusal needs a probe on a real build for that exact call. Translation (an NSException AppKit raised, after the native call, turned into AppKitException) is not a refusal. A need of code built on the extension is solved in that code, not here.

   HarfBuzz has no error object to translate. Unlike FreeType it dereferences NULL objects, so a buffer or font holding NULL is refused (`phphb_live_ptr`).
4. **Glue** is the only native code beyond the calls: handle boxing and release, struct copies in and out, the feature list (`phphb_features`), and reading an ext-freetype `FT_Face` through its `pointer()` method.
5. **ext-freetype.** `ZEND_MOD_REQUIRED("freetype")`: MINIT finds its `FT_Face` class; `hb_ft_font_create_referenced` calls `FT_Face::pointer()` for the native face. No ext-freetype C header is included.
6. **The guard.** ext-guard checks every edit to this repo in Claude Code, Cursor and the git hooks. If it blocks an edit, fix the edit; never route around it. `bindings.json` sections: `symbols` — an agent may add entries, validated against the HarfBuzz headers; `glue`, `helpers`, `sites` and `typemap` — only the maintainer (Angel) edits them. A throw on an added line needs a `/* binding:<id> */` marker naming a site, unless it sits inside a `helpers.marshal` function (`phphb_features`, `phphb_live_ptr`). One marker marks one line. A `ZEND_FUNCTION` must be written out, not made by a macro: the pre-commit hook matches each one to its stub.
7. **A kept refusal** reads `if (!PHPHB_PROBE_OFF("<id>") && (<check>))`, carries `/* binding:<id> */` on its throw line, has its `sites` entry in `bindings.json`, and a probe test in `tests/Probes` that shows the crash with the check off (`hbChild()` in `tests/Pest.php`). Probe builds use `HARFBUZZ_CONFIGURE=--enable-harfbuzz-probes`; in that build env `PHPHB_PROBE_OFF=<id>` turns one site's check off and the constant `PHPHB_PROBES` exists. Probe tests skip on release builds. Never ship a probe build.
8. **Handles.** `final`, private empty `__construct`, not cloneable, not serializable, `pointer(): int`, `static fromPointer(int $pointer): static`. One PHP object per native pointer per thread (`phphb_box`, module global `boxes`). `hb_*_destroy` releases the handle. Dropping a PHP object never calls `hb_*_destroy`.
9. **The stub is the declaration.** Edit `stubs/*.stub.php`, regenerate with `php84 /opt/homebrew/opt/php@8.4/lib/php/build/gen_stub.php stubs`, commit both. Never hand-edit `*_arginfo.h`. One `src/<Group>.c` per stub registers that stub's functions and classes; `config.m4` lists the sources.
10. **Build.** Mac: `bash install-macos.sh` into Homebrew `php@8.4` (`php84`) and `php@8.4-zts` (`zhp`), after ext-freetype. Linux: `bash install-debian-trixie.sh`. Both fail on a warning from `src/`. Pest v4 at `-d memory_limit=128M`, `XDEBUG_MODE=off`. Run the test files a change touches; gate a commit on the run's exit code.
11. **Durable facts go in `.okf`.** Update the matching concept, bump its `generated.at`, append `.okf/log.md`. The bundle documents the package, never a session.
12. **Version** is `PHP_HARFBUZZ_VERSION` in `php_harfbuzz.h`: 0.11.0. It moves only past a published tag; tags drive Packagist. `os-families`: linux, darwin.
