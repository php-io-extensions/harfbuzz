# Log

## 2026-11-05

* Bundle created with ext-harfbuzz 0.11.0: 19 functions at the HarfBuzz 8.3.0 API, the floor (Ubuntu 24.04's HarfBuzz): the hb-ft font over an ext-freetype `FT_Face`, its scale, buffers and their segment properties, `hb_shape` with features, `hb_feature_from_string`, glyph infos and positions. Built on Homebrew PHP 8.4 NTS and ZTS against HarfBuzz 14.6.0, and on Ubuntu against 8.3.0. [bindings](api/bindings.md), [handles](architecture/handles.md), [structs](architecture/structs.md), [build](runbooks/build.md).
* **Refusals**: HarfBuzz dereferences a NULL buffer or font (FreeType does not), and reads past the lengths and counts it is given. Five sites, each with a probe in `tests/Probes`: `harfbuzz-null-handle` (also an hb-ft font whose `FT_Library` was done), `harfbuzz-ft-face-null`, `harfbuzz-utf8-length` (also an item outside the text, which HarfBuzz 8.3 reads past and 14.6 clamps), `harfbuzz-language-length`, `harfbuzz-num-features`. Pass through, probed: `hb_feature_from_string` with a long `$len` (false), a second `hb_*_destroy`.
* **hb-ft and memory faces**: a font over an `FT_New_Memory_Face` face keeps working after `FT_Done_Face` and after PHP drops the face and its string: ext-freetype's native face owns the bytes. `MemoryFaceTest` covers both.
* **HarfBuzz 8.3 vs 14.6**: 8.3's hb-ft takes advances from the FreeType size and ignores `hb_font_set_scale`; 9 and newer scale them. `hb_ft_font_changed` after `FT_Set_Pixel_Sizes` gives the same advances on both.
* **Handle runtime**: identity is keyed by address and class, so a `fromPointer()` of another class does not clear a live handle. An `hb_feature_t` property after `unset()` throws PHP's uninitialized-property `Error` instead of reading as 0. Invalid UTF-8 becomes U+FFFD in the buffer.
* **Coverage**: `scripts/support.php` counts every `HB_EXTERN … name (` of the headers hb.h, hb-ot.h and hb-aat.h include, and hb-ft.h, at the 8.3.0 tag.

## 2026-11-16

* **HarfBuzz's own font loading**: `hb_blob_create_from_file`, `hb_blob_destroy`, `hb_face_create`, `hb_face_destroy` (new `hb_face` stub, handles `hb_blob_t` and `hb_face_t`) and `hb_font_create`. 24 functions. No new refusal: HarfBuzz 8.3.0 reads a NULL blob or face as the empty one, and a file that does not open is the empty blob. [bindings](api/bindings.md), [handles](architecture/handles.md).
* **ext-freetype is optional**: `ZEND_MOD_OPTIONAL("freetype")` and `PHP_ADD_EXTENSION_DEP(harfbuzz, freetype, true)`. hb-ft moved to its own `hb_ft` stub, registered only when ext-freetype's classes exist. The installers no longer stop without it; CI loads the module alone. `OptionalFreetypeTest` loads it with `-n` in a child.
* **Mutations**: the new tests fail when the dependency is required again, when hb-ft is registered without ext-freetype or not at all with it, when the face index is dropped, when a blob or face is not released, and when a NULL blob or face is passed in place of the handle or refused. A destroy that skips the native call is not caught: the leak is not visible through any bound call.
* **Not run on Linux yet**: Mac only (HarfBuzz 14.6.0, NTS and ZTS). The tests' 1233 advance was measured on a DejaVu Sans Mono copy on the Mac as well (2048 units per em), not on Debian's package.
* **hb_face_count**: the number of faces in a blob, 0 for a file that is not a font or does not open (HarfBuzz reads both as the empty face, and takes any index of a single font as its one face). 25 functions. No refusal: HarfBuzz answers 0 for a NULL blob.
* **hb_font_set_variations**: the instance of a variable font a font shapes at, as a list of `hb_variation_t` (`tag`, `value`), copied by `phphb_variations` (a `helpers.marshal` function). 26 functions. A sixth refusal, `harfbuzz-variations-length`: a count below 0 or past the list, which HarfBuzz reads past; its probe uses a variable font, since for a font without axes the compiler drops the reads. `tests/Pest.php` `variableFont()` writes the font the tests shape with ('wght' 100..400..900, 'A' 500 wide, +200 at the maximum, -100 at the minimum): advances 700, 600, 450, 400 at wght 900, 650, 250, 100. Six breaks of the two bindings each fail a test.
